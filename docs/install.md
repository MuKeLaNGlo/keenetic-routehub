# Установка на Keenetic

Пакет RouteHub предназначен для Keenetic Hopper KN-3811 с работающим Entware ARM64 и архитектурой `aarch64-3.10`. Команды ниже рассчитаны на стандартный Entware в `/opt`, где доступна административная оболочка Linux.

## 1. Установить пакет

[Соберите IPK](build.md#пакет-для-keenetic) и скопируйте его на роутер. В примере файл переименован в `/tmp/routehub.ipk`.

```sh
opkg print-architecture
opkg update
opkg install /tmp/routehub.ipk
```

Установщик подключает зависимость `xray-core` из Entware. Начальный план находится в `/opt/etc/routehub/config.json`. Чистая установка оставляет службу и перехват LAN выключенными. Размещение Entware во внутренней памяти зависит от конфигурации KeeneticOS. Для нестандартного корня установки хук в пакете требует отдельного скрипта запуска. Перед обновлением сохраните приватную копию каталога `/opt/etc/routehub` и предыдущий IPK.

## 2. Открыть панель на loopback

Для начального входа создайте случайный ключ. Команда сохраняет его в приватный файл и оставляет существующий ключ без изменений.

```sh
umask 077
if [ ! -s /opt/etc/routehub/panel.key ]; then
  dd if=/dev/urandom bs=24 count=1 2>/dev/null | base64 > /opt/etc/routehub/panel.key
fi
chmod 0600 /opt/etc/routehub/panel.key
/opt/sbin/routehub check -config /opt/etc/routehub/config.json
/opt/etc/init.d/S98routehub start-once
```

Панель слушает `127.0.0.1:18952`, SOCKS5 — `127.0.0.1:18953`. Панель предназначена для доверенного доступа. Если административный SSH-сервер поддерживает переадресацию, откройте туннель с компьютера. Замените `root@router` своим именем пользователя и адресом роутера.

```sh
ssh -N -L 18952:127.0.0.1:18952 -L 18953:127.0.0.1:18953 root@router
```

Откройте панель в браузере и введите ключ из `panel.key`. В разделе «Обслуживание → Доступ» можно установить пароль. [Локальная панель через SSH](http://127.0.0.1:18952/)

Проверка явного SOCKS5 из отдельного терминала.

```sh
curl --socks5-hostname 127.0.0.1:18953 https://example.com/
```

## 3. Подключить домашнюю сеть

Для доступа к панели из LAN задайте `panelHost` и `panelNetwork` в `config.json`. Используйте фактический частный IPv4-адрес роутера и его подсеть. Ограничьте доступ доверенной сетью.

Для обработки клиентского трафика добавьте секцию `transparent`. Начните с одного адреса `/32`. В примере роутер использует адрес `192.168.50.1`, а тестовый клиент — `192.168.50.20`. Замените адреса и имя Linux-интерфейса своими.

```json
{
  "panelPort": 18952,
  "socksPort": 18953,
  "panelHost": "192.168.50.1",
  "panelNetwork": "192.168.50.0/24",
  "defaultTarget": "direct",
  "transparent": {
    "mode": "redirect-tcp",
    "interface": "br0",
    "source": "192.168.50.20/32",
    "port": 18954
  },
  "profiles": [],
  "rules": []
}
```

Для перехвата нужны совместимые `iptables` и `ip`. Для перенаправления DNS в LAN и Zapret установите `flock` командой `opkg install flock`. Для Zapret отдельно требуется `nfqws2`. У `tproxy` есть дополнительное требование к поддержке ядра. Подробности и границы перехвата описаны в [документации адаптера](../module/redirect/README.md).

```sh
/opt/sbin/routehub check -config /opt/etc/routehub/config.json -allow-lan
touch /opt/etc/routehub/allow-lan
/opt/etc/init.d/S98routehub restart
/opt/etc/init.d/S98routehub status
```

Проверьте прямой маршрут и нужный VPN с тестового клиента. После проверки расширьте `transparent.source` до управляемой подсети, если нужно подключить всю сеть. Для правил отдельного устройства закрепите его IPv4 по MAC в DHCP Keenetic.

В разделе «DNS» можно проверить резолвер и подключить домашнюю сеть после расширения перехвата до подсети, включающей адрес роутера. В разделе «Zapret» доступны отдельные стратегии YouTube и Discord. [Резолвер](../module/dns/README.md) · [Интеграция Zapret](../module/zapret/README.md)

## Запуск и откат

| Команда `/opt/etc/init.d/S98routehub` | Действие |
| --- | --- |
| `start-once` | Запуск вручную. |
| `status` | Проверка процесса. |
| `stop` | Остановка и снятие правил RouteHub. |
| `enable` | Разрешение автозапуска Entware. |
| `disable` | Остановка и удаление разрешения на автозапуск Entware. |

Чтобы вернуть обычное прохождение клиентского трафика при диагностике, остановите RouteHub. Для отката пакета остановите службу и установите сохранённый IPK, например `opkg --force-downgrade install /tmp/routehub-previous.ipk`. При необходимости восстановите конфигурацию из копии и проверьте её перед запуском. Журнал службы находится в `/opt/var/log/routehub.log`.
