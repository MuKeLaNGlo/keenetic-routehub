# Демон Go и интеграции Entware

Этот каталог содержит исходную реализацию на Go и общие компоненты пакета. Рабочий демон на Rust находится в [module-rust](../module-rust/). Для основного пакета используйте [инструкцию сборки Rust](../docs/build.md).

RouteHub запускает Xray и выбирает маршрут по домену, IPv4/IPv6 CIDR, TCP/UDP и порту. Первое совпадение определяет выход. По умолчанию трафик идёт напрямую. Несколько VPN-профилей могут использоваться одновременно для разных назначений.

| Выход | Что указать |
| --- | --- |
| VLESS | Ссылку `vless://` или объект `outbound` из конфигурации Xray. Импорт понимает TLS, REALITY, RAW, WebSocket, XHTTP, gRPC и HTTP Upgrade. |
| Hysteria2 | Ссылку `hysteria2://` или `hy2://` с TLS. Поддерживается Salamander. Для дополнительных настроек можно передать JSON-выход Xray. |
| Trojan | Ссылку `trojan://` с TLS или совместимый объект `outbound` Xray. |
| AmneziaWG | Клиентский файл 2.0 или 3.1. RouteHub поднимает туннель в userspace и передаёт TCP и UDP через локальный SOCKS. Можно подключить существующий интерфейс WireGuard ASC. [Настройка адаптера](awg/README.md). |
| Zapret | Маршрут `zapret` с отдельным адаптером `nfqws2`. В шаблоне так отмечены YouTube, YouTube CDN и Discord. Для включения нужен профиль Zapret 2, проверенный на вашем провайдере. [Настройка адаптера](zapret/README.md). |

Подробности полей описаны в [документации VLESS](https://xtls.github.io/en/config/outbounds/vless.html), [Hysteria2](https://xtls.github.io/en/config/outbounds/hysteria.html), [Trojan](https://xtls.github.io/en/config/outbounds/trojan.html) и [KeeneticOS WireGuard ASC](https://support.keenetic.com/hopper/kn-3811/en/107768-os-5-1.html).

## Режимы работы

- **Явный прокси.** SOCKS5 TCP/UDP доступен на `127.0.0.1:18953`. Панель по умолчанию слушает loopback. Поля `panelHost` и `panelNetwork` открывают её на заданном частном IPv4 и ограничивают доступ домашней подсетью. DNS, маршрутизация LAN и firewall в этом режиме не изменяются.
- **Перехват LAN.** Требует секцию `transparent`, отдельное разрешение `-allow-lan` и доступные TProxy и policy routing. Текущая версия перехватывает IPv4 для заданного интерфейса и CIDR. DNS и IPv6 остаются по штатным путям. Активные цепочки StealthSurf блокируют запуск перехвата RouteHub. Перед включением проверьте сценарий на одном выделенном IPv4-клиенте. [Устройство перехвата](redirect/README.md).

Имя домена для явного прокси берётся из SOCKS-запроса. В прозрачном режиме Xray использует доступные признаки HTTP, TLS и QUIC. Для IP-потоков и ненаблюдаемого домена нужны проверенные CIDR-правила. Это особенно важно для UDP голоса Discord.

## Конфигурация

Рабочий файл `/opt/etc/routehub/config.json` имеет права `0600`. Начните с [примеров](profiles.example.json). Секрет профиля хранится в `uri`, `outbound` или `awgConfig`. Ключ из `-panel-key-file` служит начальным паролем панели и ключом для старого API. Храните его отдельным файлом с правами `0600`. RouteHub проверяет новую конфигурацию Xray, применяет её и атомарно сохраняет. При ошибке остаётся прежняя версия.

- **Конфиги.** Поддерживаются ссылки и совместимые профили Xray, sing-box, Mihomo, Hysteria2 и AmneziaWG. Панель определяет протокол и показывает настройки перед сохранением. Выход по умолчанию применяется после правил, поэтому их порядок и назначения сохраняются при смене конфигурации.
- **Статистика.** График на обзоре строится по счётчикам IPv4-интерфейса с маршрутом по умолчанию. Панель измеряет скорость каждые 5 секунд. Последний час хранится в памяти процесса и собирается заново после его перезапуска.
- **DNS.** Резолвер RouteHub слушает TCP и UDP на порту 18955. Поддерживаются обычный DNS, DoH, DoT, резервный сервер, TTL-кэш, списки HaGeZi и исключения по доменам. Опция DNS для домашней сети переключает запросы IPv4-клиентов к адресу роутера на порту 53. Перед переключением RouteHub проверяет ответ выбранного DNS. [Интеграция с Keenetic](dns/README.md).
- **Устройства.** Список обновляется из Keenetic автоматически. Можно оставить только общую политику, проверить личные правила перед общими либо проверить личные правила перед собственным выходом по умолчанию. Для личных правил нужен IPv4, зарезервированный за MAC в штатном DHCP, и включённый IPv4-перехват RouteHub.
- **Импорт и экспорт.** Панель распознаёт TXT, Comma/CSV и JSON, включая выгрузки IPLIST, а также Keenetic Routes BAT, DNS и KVAS, sing-box JSON/SRS, Dnsmasq, ClashX, PAC и Amnezia. Файл может содержать до 20 000 правил и занимать до 2 МиБ. Для v2fly Domain List Community поддерживается файл без расширения, `full:` означает точное совпадение. Директивы `include:` нужно разворачивать до загрузки. CIDR и домены сохраняют порядок. Можно скачать правила любой области или конфигурацию с профилями.
- **Zapret.** Переключатели YouTube и Discord управляют своими наборами доменных правил. Правила, добавленные вручную, имеют приоритет. Для каждого сервиса можно проверить HTTPS из панели. Проверка требует работающего адаптера `nfqws2` и прозрачного режима. Она показывает доступность проверяемого адреса, отдельно от голосовых каналов Discord и воспроизведения видео YouTube.

```sh
/opt/sbin/routehub check -config /opt/etc/routehub/config.json
/opt/etc/init.d/S98routehub start-once
curl --socks5-hostname 127.0.0.1:18953 https://example.com/
/opt/etc/init.d/S98routehub stop
```

Панель проверяет первое совпадение правила. SOCKS-запрос проверяет фактический доступ через выбранный выход. Результат в панели сам по себе не подтверждает VPN handshake. Если выбранный VPN недоступен, затронутое соединение завершается ошибкой, а маршрут по умолчанию для остальных назначений продолжает работать.

## Сборка и проверка

Команда из каталога модуля. Сборка создаёт ARM64 IPK в соседнем каталоге `dist`. Пакет зависит от `xray-core`, автозапуск по умолчанию выключен. [Порядок установки и удаления](packaging/README.md).

```sh
python3 packaging/build_ipk.py
```

Веб-панель встроена в исполняемый файл RouteHub. После изменений в `panel/src` пересоберите её командой `python3 packaging/build_ipk.py --rebuild-panel`. Предыдущая панель доступна по `/legacy` на том же адресе. [Сборка и запуск макета](panel/README.md).
