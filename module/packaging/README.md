# Пакет RouteHub для Keenetic Entware

Сборщик создаёт пакет Entware `aarch64-3.10` со статическим демоном Rust и встроенной веб-панелью. Для сборки нужны Python 3.11 или новее, Docker с поддержкой ARM64, Node.js 22 и pnpm.

```sh
python3 module/packaging/build_ipk.py --rebuild-panel
```

Команда выполняется из корня репозитория. Подробности о версиях и упаковке готового бинарника есть в [инструкции сборки](../../docs/build.md). Пакет использует `xray-core` из Entware, сохраняет рабочую конфигурацию в `/opt/etc/routehub/config.json` и оставляет службу выключенной после чистой установки.

После установки и настройки конфига службой можно управлять явно.

| Команда после `/opt/etc/init.d/S98routehub` | Результат |
| --- | --- |
| `start-once` | Запустить вручную. |
| `status` | Показать состояние процесса. |
| `stop` | Дождаться штатной остановки. |
| `restart` | Перезапустить активную службу или запустить её, если включён автозапуск. |
| `enable` | Включить автозапуск Entware. |
| `start` | Запустить, если включён автозапуск. |
| `disable` | Выключить автозапуск и остановить службу. |

При обычном запуске прокси и панель слушают loopback. Для прозрачной маршрутизации нужны отдельные настройки в конфиге и созданный администратором файл `/opt/etc/routehub/allow-lan`. Остановка завершает процесс по SIGTERM и оставляет журнал `/opt/var/log/routehub.log`. Служба хранит текущий файл и две предыдущие копии по 256 КиБ. Запись приостанавливается, если на разделе нельзя сохранить резерв свободного места в 8 МиБ. Удаление через `opkg remove routehub` сначала останавливает службу и подключаемые обработчики трафика.
