# Веб-панель RouteHub

RouteHub раздаёт встроенную панель по `/` на своём HTTP-адресе. Панель обращается к API демона с того же адреса. URL старого интерфейса — `/legacy`.

При первом входе используйте действующий ключ RouteHub. Новый пароль задаётся в разделе «Обслуживание → Доступ». Модуль хранит проверочное значение отдельно от плана маршрутизации и завершает старые сессии после смены пароля. Административный ключ для старой панели и API задаётся файлом `-panel-key-file`.

«Ревизии» сохраняют до шести предыдущих состояний плана маршрутизации в приватном каталоге рядом с конфигурацией с общим лимитом 8 МиБ. Восстановление создаёт новую ревизию. Текущие настройки резолвера, автозапуска и выбранного VPN-выхода хранятся отдельно. «Копии» позволяют выгрузить защищённый экспорт конфигурации и правила выбранной области.

Панель показывает найденные сети Keenetic и отмечает доступный перехват. Для текущей версии один настроенный сегмент управляется RouteHub, остальные доступны для просмотра. Проверка маршрута с роутера подтверждает запрос через указанный выход. Трафик клиента и результат обработки Zapret проверяются отдельно.

В разделе «Выходы VPN → Подписки» можно добавить HTTPS-источник VLESS, просмотреть изменения, проверить отдельные профили до сохранения и настроить периодическое обновление. Поддерживаются текстовые списки, Base64 и самостоятельные выходы VLESS в JSON Xray. При ошибке загрузки сохраняется предыдущий рабочий список. Полные URL подписок и ключи профилей доступны только при вводе и в приватной конфигурации модуля.

В разделе «Правила → Все области» доступны фильтры по маршруту и состоянию, массовые действия и перенос правил между общей и действующими личными политиками. В «Устройствах» доступны фильтры по резерву IPv4 и наличию личной политики.

Доступность функций определяется API установленного демона. Актуальные ограничения указаны в [описании RouteHub](../../README.md#совместимость).

## Сборка

Из каталога `panel` с Node.js и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm build
```

После сборки `dist/index.html` содержит HTML, стили, скрипты и шрифты. Из корня репозитория соберите пакет командой `python3 module/packaging/build_ipk.py`. Флаг `--rebuild-panel` обновит HTML перед сборкой демона Rust.

## Макет с демонстрационными данными

```sh
pnpm dev --host 127.0.0.1
pnpm build:demo
```

Демонстрационная сборка находится в `dist-demo/index.html` и работает отдельно от демона.
